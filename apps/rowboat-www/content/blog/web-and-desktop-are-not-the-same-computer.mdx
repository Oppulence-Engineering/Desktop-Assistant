Use web for the shared queue and for days the laptop is shut. Use desktop when the work is happening next to you, or when the file should never leave the disk.

Both talk to the same API. Desktop is also a local observation node: vault, live notes, meeting capture, in-app browser, MCP.

## What a browser tab cannot do

It cannot record the room you are already in. It cannot watch a local Markdown folder. It cannot run Whisper on a file that must stay put.

Plenty of people will only use web. That is fine. Desktop is there for the jobs a tab cannot do.

Signed-in desktops share the same accounts as the browser. First-run also lets you skip the cloud ledger and bring your own keys.
